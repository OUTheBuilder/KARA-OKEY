# Online / Offline mode

The clone now has a connection-mode toggle.

- **Offline mode:** local library/navigation remain available and the Online screen is disabled.
- **Online mode:** enables an Online Karaoke screen where the user can search YouTube for karaoke music videos.
- Search opens YouTube's search results inside the app's WebView.
- The app does not download or extract YouTube media; playback remains subject to YouTube's service rules and availability.
- Internet permission is declared only for the online functionality.
